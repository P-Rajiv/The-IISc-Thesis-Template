Synthetic Chest X-ray (CXR) image generation has many uses, given there is scarcity
of CXR data to train models. By leveraging generative adversarial networks (GANs)
and diffusion models, previous works \cite{Nath2013} have shown that synthetic datasets
help mitigate this problem of scarcity. These synthetic images facilitate data
augmentation for pathologies and improve model classification accuracy thus
providing a scalable solution in this domain. In this work, we explore the
current methodologies for generating high-fidelity medical images and evaluate
their impact on classification accuracy.
